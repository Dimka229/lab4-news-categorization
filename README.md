# Лабораторная работа №4: Обработка текстов

**Дисциплина:** Прикладные задачи искусственного интеллекта  
**Вариант:** 1 (Рубрикация новостей, AG News)

## Описание
Сравнение трех подходов к классификации текстов (4 класса: World, Sports, Business, Sci/Tech):
* **Подход А:** TF-IDF + Логистическая регрессия (Macro-F1 = 0.8310)
* **Подход В (1):** Дообучение rubert-tiny2 (Macro-F1 = 0.8119)
* **Подход В (2):** Замороженные эмбеддинги e5-small + LogReg (Macro-F1 = 0.8743 — ЛУЧШИЙ)
* **Подход С:** LLM Qwen2.5-3B (zero-shot, Macro-F1 = 0.7120 на 50 текстах)

## Файлы
* `lab4ИИ.ipynb` — ноутбук со всеми экспериментами.
* `test.csv` — единая тестовая выборка (300 текстов), использованная для оценки всех подходов.
